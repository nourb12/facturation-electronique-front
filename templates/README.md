## 🎯 Comment faire les screenshots

### Méthode 1 : Screenshot Chrome (RECOMMANDÉE)
1. Ouvre le fichier HTML dans **Google Chrome**
2. Appuie sur **F12** pour ouvrir DevTools
3. Appuie sur **Ctrl + Shift + P**
4. Tape "**screenshot**"
5. Choisis "**Capture full size screenshot**"
6. L'image PNG est téléchargée automatiquement

### Méthode 2 : Windows Snipping Tool
1. Double-clic sur le fichier HTML
2. Appuie sur **F11** (plein écran)
3. **Windows + Shift + S**
4. Sélectionne la zone
5. Sauvegarde en PNG
